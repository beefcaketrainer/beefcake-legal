Frequently asked questions

How do I start my first workout?

On the Workouts tab, tap Start Workout for today's planned session, or Empty workout to build one as you go. Enter the weight and reps for each set, then tap Finish Workout.

How do I set up a training program?

Go to the Program tab and create a new program, then add exercises to each training day. To start from a ready-made plan, go to Settings › Add sample program and pick Full Body, 5×5 Strength, Upper / Lower, Push / Pull / Legs or Body Part Split.

What does "LW" mean?

LW is the heaviest weight you lifted for that exercise the last time you did it. It fills in by itself. The chip under the exercise name, such as "+10 lbs vs LW", compares your heaviest set today with LW. Blue means you beat it.

How are personal records worked out?

When you finish a workout, BeefCake checks each exercise against everything you've logged before and records any new best, with an estimated one-rep max. They appear on the Progress tab.

Can I switch between lbs and kg?

Yes: Settings › Show weights in. Everything you've logged is converted, and nothing is lost. Body measurements switch between inches and cm on the Body tab.

How do I move my data to a new phone?

On the old phone, go to Settings › Export file and save the backup somewhere you can reach from the new phone, such as iCloud Drive. On the new phone, go to Settings › Import file, pick the file, then choose Merge to add it to what's there, or Replace to start fresh from the backup.

If I delete the app, do I lose my data?

Yes. Your data is stored only on your phone, so deleting BeefCake erases it. Export a backup file first if you want to keep it.

How do I delete all my data?

Settings › Erase all data. This can't be undone, so export a backup first if you might want it back.

The text to my partner didn't send.

BeefCake opens Messages with the text filled in, and you tap send. If Messages doesn't open, check the partner's phone number in Settings › Message or edit partner. With no number saved, the share sheet opens instead.

Is there a subscription?

No. BeefCake is a one-time purchase. Pay once, no subscription, ever.

How do I get a refund?

App Store purchases are refunded by Apple. Go to reportaproblem.apple.com.
